# Sample Pharmacy Manager exports

These spreadsheets are synthetic. They copy the layout of Positive Solutions (PSL) Pharmacy Manager
report exports so the parser tests can run, but every value in them is made up: the branches are
"Branch A" and "Branch B", the script references are placeholders, and there is no patient,
prescriber or pharmacy data. Never add a real export to this folder or anywhere in the repository.

The date and time in each name follow PSL's own file naming, which the parser reads for the stock
snapshot date.
